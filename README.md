# Sudoku для Android

Офлайн-гра українською мовою. Класичні та щоденні головоломки генеруються на пристрої. SQLite зберігає партії, нотатки, історію ходів, результати й налаштування.

Стек — React Native, Expo SDK 58, Expo Router і TypeScript у строгому режимі. Zustand керує поточною сесією. Expo SQLite відповідає за збереження, Expo Haptics — за тактильний відгук, Reanimated і Gesture Handler — за анімації й підтримку жестів навігації.

## Запуск на Android

Встановіть Node.js 24 LTS, Android Studio, JDK 17 або новішу сумісну версію та Android SDK Platform 37. Увімкніть налагодження USB на пристрої або запустіть емулятор. Налаштуйте `ANDROID_HOME` і додайте `platform-tools` до `PATH`.

```sh
npm ci
npm run android
```

Для наступних змін JavaScript можна запустити Metro командою `npm start`. Під час розробки Metro обслуговує локальний пакет. Збірка для встановлення містить JavaScript і ресурси для гри офлайн.

Якщо на Windows Ninja повідомляє про перевищення довжини шляху, скоротіть шлях до проєкту й `GRADLE_USER_HOME`. Для модуля, на якому зупинилася збірка, також можна задати короткий `buildStagingDirectory` і передати CMake аргумент `-DCMAKE_OBJECT_PATH_MAX=245`.

## Збірка APK та AAB

Для першої збірки під’єднайте репозиторій до власного проєкту Expo. EAS CLI запропонує налаштувати Android-ключ підпису. Обліковий запис Expo потрібен розробнику для EAS Build. Гравці можуть користуватися застосунком без облікового запису.

```sh
npx eas-cli@latest login
npx eas-cli@latest init
npx eas-cli@latest build --platform android --profile preview
npx eas-cli@latest build --platform android --profile production
```

Профіль `preview` створює APK для встановлення на пристрій. Профіль `production` створює AAB для Google Play. Профілі задано в `eas.json`.

## Sudoku Engine

Поле складається з 81 значення. Нуль означає порожню клітинку. Розв’язувач підтримує бітові маски рядків, стовпців і секторів та обирає порожню клітинку з найменшою кількістю кандидатів (MRV). Пошук повертає перший розв’язок або рахує розв’язки до заданого ліміту.

Генератор спочатку заповнює поле з перемішаним порядком кандидатів, потім видаляє числа в перемішаному порядку. Він залишає видалення, лише якщо пошук підтвердив єдиний розв’язок. Складність перевіряється повним проходженням логічного розв’язувача. Пошук і кількість спроб обмежені. Генерація періодично повертає керування інтерфейсу й підтримує переривання через `AbortSignal`. Коли бюджет спроб вичерпано, генератор перемішує перевірені базові головоломки того самого рівня допустимими перестановками та звіряє рівень отриманого поля.

| Рівень | Критерій логічного проходження |
| --- | --- |
| Легкий | До 42 кроків із Naked Single |
| Середній | Понад 42 кроки з Naked Single або потрібен Hidden Single |
| Складний | Потрібні Locked Candidates або Naked Pair |
| Експерт | Потрібні Hidden Pair або X-Wing |

Рівень визначає найскладніша застосована техніка з урахуванням порога кроків для легкого рівня. Пояснення використовує наступний доступний логічний крок. Відкриття числа записує його як звичайний хід, тому його можна скасувати.

Щоденне Sudoku використовує локальну календарну дату у форматі `YYYY-MM-DD`, версію генератора й фіксоване початкове значення PRNG. SQLite зберігає першу головоломку дня та її результат. Щоденна серія зберігається до кінця дня, якщо остання перемога була вчора.

## Збереження й таймер

Стан поля та історія ходів записуються однією транзакцією. Схема оновлюється послідовними міграціями SQLite. Статистика обчислюється з партій. Частка завершених враховує перемоги й партії, завершені за лімітом помилок. Ліміт діє з увімкненою перевіркою помилок. Завершене щоденне завдання зберігає один результат для дати.

Таймер використовує монотонний годинник і рахує час, поки екран гри відкритий, застосунок активний і партія триває. Під час гри час записується приблизно кожні дві секунди, а під час паузи, виходу з екрана й переходу у фон — одразу. Після примусового завершення процесу таймер відновлюється з останнього запису.

## Перевірки

```sh
npm run typecheck
npm test
npx expo install --check
npx expo export --platform android
```

`npm test` запускає Jest із пресетом jest-expo, зокрема стрес-тест 240 головоломок, а потім інтеграційні тести на реальному SQLite через `node:sqlite`. Для окремого запуску тестів збереження використайте `npm run test:database`.

Рушій також перевірено на Android 10, API 29, x86, у Expo Go 58 з Hermes і двома віртуальними ядрами. Вимірювання охоплює по шість головоломок кожного рівня з фіксованими seed. Під час вимірювання на ПК тривала збірка Gradle.

| Рівень | Медіана генерації | Найбільший час |
| --- | --- | --- |
| Легкий | 124 мс | 2263 мс |
| Середній | 109 мс | 146 мс |
| Складний | 1247 мс | 2459 мс |
| Експерт | 2146 мс | 2633 мс |
