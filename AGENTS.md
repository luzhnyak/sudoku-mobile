# Sudoku mobile

## Архітектура

- `src/engine` містить чистий TypeScript для Sudoku. Залишайте його незалежним від React Native, Zustand і SQLite.
- `src/game` містить чисті правила партії. Зміна клітинки й автоматичне очищення нотаток входять до одного ходу.
- `src/store` керує сесією, таймером та автозбереженням. Запис у SQLite централізовано в `src/database`.
- Екрани Expo Router знаходяться в `app`. Компоненти використовують палітру з `src/theme` і рядки з `src/localization`.

## Інваріанти

- Поле має 81 значення від 0 до 9. Початкові цифри незмінні. Кожна згенерована головоломка має рівно один правильний розв’язок і відповідає заданому рівню за логічним проходженням.
- Чисті функції рушія зберігають вхідні поля. Дедукції підказок мають бути коректними для поточного поля.
- Щоденний seed відтворюється з дати, версії й фіксованого значення. Збільшуйте `GENERATOR_VERSION`, якщо зміна впливає на результат генерації для seed. Збережені щоденні головоломки та підсумкові результати мають залишатися доступними після оновлення.
- Зберігайте стан поля та історію атомарно. Для змін схеми додавайте міграції. Підсумок партії фіксується один раз.
- Зберігайте автономність застосунку. Ігровий процес, налаштування й статистика працюють із даними на пристрої.

Після змін запускайте `npm run typecheck` і `npm test`. Зміни залежностей звіряйте через `npx expo install --check`. Перевіряйте зміни інтерфейсу та життєвого циклу на Android.
